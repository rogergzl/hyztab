离线教程

把新标签页变成你的工作台

这份教程覆盖「花与竹标签」的日常操作与进阶设置。所有配置保存在本机浏览器， 修改后自动生效，刷新页面不会丢失。

从任意新标签页点击左下角设置按钮，拉到侧边栏底部即可再次打开本页。

1. 快速开始

全新安装或点击「重置」后，页面默认显示四个组件：

  • 顶部居中：时间、问候语、搜索框（默认 Bing）
  • 底部居中：快速链接网格（默认 6 列 × 4 行）

网格会按屏幕高度自动缩放，1280×720、1366×768、1920×1080 下都保持间距。 组件的位置与大小可以在侧边栏「组件 → 显示设置」中逐个调整； 现有用户的手动设置不会被默认值覆盖。

侧边栏按「组件实例」列出。若出现多个同名组件，说明重复添加了， 用每项左侧的垃圾桶图标删掉多余的即可。

2. 快速链接

链接在主页上直接管理，不需要在侧边栏逐条配置。

想做的事操作
新增链接在快速链接区域右键
编辑链接右键某个具体链接
删除链接右键链接 → 面板左下角「删除」
配置空槽位左键点击带 + 的格子
访问链接左键点击，或按数字键 1 ~ 9
翻页鼠标滚轮、页码圆点、左右箭头，或按住拖动

网格与换位

网格尺寸在侧边栏「快速链接网格」里设置：横向 1~16 列、纵向 1~6 行， 整页共享同一份配置。每一格都是独立槽位，删除链接只清空该格，后面的链接不会前移。

按住方块约 0.4 秒即可拾起并拖动，目标格会高亮；松手后与高亮格交换位置， 其它格子原地不动，空槽位也能交换。超出一页的链接可用滚轮或拖动翻页。

名称与图标

「完整名称」作为底层数据保留，鼠标悬浮时显示；「短名称」显示在图标下方， 留空时自动从完整名称推断。图标可选站点 favicon，或上传本地图片（自动裁剪为 64×64）。 自定义图标只存本机，不随分享上传。

3. 代理访问

在侧边栏「快速链接网格 → 默认代理节点」里预先配置多个「名称 + 地址」， 然后在链接配置面板勾选「代理访问」，直接展开下拉框选择节点； 也可以选「自定义地址」临时填写。

  • 地址支持 主机:端口、http://…、socks5://…、socks4://…
  • 修改节点地址会同步到所有选用它的链接；删除节点则回退到链接原地址
  • 「代理兜底」留空则未命中域名直连；填本地代理（如 Clash）则先走它，连不上再直连
这是浏览器级 PAC 按域名路由，不是按单个链接或标签页。 同域名的其它页面也会走同一代理，子域名需要单独配置。 没有任何链接启用代理时，扩展会清除 PAC，把控制权交还系统。

4. 标签分享

无需账号登录，把配置好的链接发给另一个人；双方各自持有一对密钥。

先设置分组（推荐）

只有同一分组的用户才能互相看到、互相分享。新建密钥时填写 「分组名 + 密码」就会创建分组；别人用相同的分组名和密码加入，即可互传。 分组密码只在加入时用一次，不会保存，也不写进导出的设置文件。

  • 不填分组即归入「未分组」，未分组用户之间互通
  • 密码错误会被服务端直接拒绝，不会悄悄另建同名分组
  • 每个本地密钥可以单独设置或切换分组

发布与接收

  1. 在侧边栏「标签分享」填入中转服务地址并点击「连接」。
  2. 填写密钥名称（可选填分组名与密码），点击「生成密钥」；服务端只存公钥与指纹。
  3. 在链接配置面板勾选「标签分享」，选择使用身份与接收用户，点击「发布分享」。
  4. 接收用户按分组列出，可整组「全选」；对方也能在侧边栏「收到的分享」里手动添加。
  5. 链接更新后先「更新分享」；接收方在网格下方点「刷新分享」手动拉取。

是否采纳对方的配置

发布者总会把名称、图标与代理设置一起发出去；接收方在侧边栏 「收到的分享」里可以决定是否采纳：勾选「应用对方配置」后添加，会连名称、图标与 代理一起写入；取消勾选则只添加网址，自己重新命名与取图标。上传的自定义图标 始终不分享（只存在本机）。

自动接受

侧边栏「自动接受」里勾选某个用户或某个分组后，来自它的分享会直接写入快速链接； 没有勾选的需要手动点「添加」。刷新列表时才会检查一次。

删除密钥

在侧边栏删除密钥会同时向服务端注销并撤销它发布的分享，避免服务端残留旧身份、 出现多个同名用户。

临时局域网分享可双击仓库根目录的「一键启动分享服务.bat」，窗口会打印局域网地址； 长期运行用 npm run share-server，默认监听 127.0.0.1:8787。私钥只保存在本机，不上传，也不包含在导出的设置文件中。 生产环境请放在 HTTPS 反向代理之后。

5. 书签同步

快速链接会镜像到书签栏文件夹「标签页备份书签，请勿删除」，默认开启。 书签只保存链接名称与网址，用于备份和跨浏览器查看。

  • 链接身份绑定稳定 id；改网址或名称不会生成重复书签
  • 只删除本扩展自己创建、且已无对应链接的书签
  • 删除链接后需手动同步；拖动换位不会改变书签文件夹顺序

建议在做大调整前点一次「导出」，保存为 花与竹标签-设置.json；需要恢复时用「导入」。 「重置」会回到本教程开头描述的默认布局。

导入是整体覆盖：会先清空当前配置再写入文件内容，不会与现有配置叠加。 导出文件按设计不含分享私钥，导入时会按指纹保留本机原有的私钥， 所以换设备导入后仍需重新生成密钥。

7. 常见问题

安装时提示「更改代理设置」？

浏览器规定代理权限必须在安装期申请，无法改成按需授权；不使用代理功能时它不会接管网络。

读取站点真实名称为什么需要额外权限？

只有主动打开该开关时才申请 <all_urls>，关闭即交还；未开启时仅用域名推断名称。

分享链接更新后对方没变化？

发布者要点「更新分享」，接收方要点「刷新分享」；同步是手动的，不会自动覆盖本地内容。

悬浮提示被裁切？

弹窗会按内容自动换行，首/末列贴边对齐，顶行翻到下方；若仍异常请确认使用的是当前版本。
