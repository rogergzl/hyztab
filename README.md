# 花与竹标签

可自定义的 Chrome / Edge 新标签页扩展。源码公开，请自行查阅。

## 项目内容

| 模块 | 现有内容 |
| --- | --- |
| 快速链接网格 | 行列 1~16 × 1~6（默认 6×4）；每格独立槽位；右键新增 / 编辑、左键访问、`1`~`9` 直达；滚轮 / 拖动 / 页码翻页；长按 0.4 秒拖动重排 |
| 名称与图标 | 短名称、完整名称；站点 favicon 或本地上传；可选读取站点 `<title>` |
| 书签文件夹 | 书签栏「标签页备份书签，请勿删除」，默认开启；镜像链接名称与网址；删除项手动同步 |
| 背景 | Bing 每日壁纸、随机动图、纯色、渐变、自定义上传 |
| 页面组件 | 15 个组件插件（时钟、问候语、搜索、待办、笔记、天气、GitHub、NBA、文学钟、留言、笑话、工时、IP 信息等），可摆放与缩放 |
| 数据保存 | 配置 → `chrome.storage.sync`（自动分片）；自定义图标 → IndexedDB；快速链接 → 书签文件夹；整套设置 → 导入 / 导出 `花与竹标签-设置.json` |

书签文件夹仅含链接名称与网址。

## 优点

- 扩展 ID 固定：`ahikgnldomceknpfnkdcfhcghfiodbdp`
- `storage.sync` 超限自动分片；自定义图标不占同步配额
- 默认图源国内可用（Bing / 自定义动图地址）
- 固定外框，行列变化时格子等比缩放；弹窗横向自动换行
- 默认权限仅 `storage` / `favicon` / `bookmarks`；`<all_urls>` 按需申请、可撤回
- 书签同步默认开启，只删自有书签，删除需手动确认
