# 花与竹标签

一款可自定义的 **Chrome / Edge 新标签页扩展**：把新标签页变成一个可以自由摆放的工作台。

- 主页：<https://aphqsia.com/>
- 开源协议：GPL-3.0（基于 [Tabliss](https://github.com/joelshepherd/tabliss) 二次开发）
- 扩展 ID：`ahikgnldomceknpfnkdcfhcghfiodbdp`（固定，重装不丢数据）

## 它做什么

打开新标签页，你会看到时间与问候语，下面是搜索框和一个可自定义的快捷链接网格。
所有组件都能拖动位置、调整大小；快捷链接支持多页管理、逐条设置代理、备份到浏览器书签。
配色、背景、字体都可改，配置跟随浏览器账号同步。

不需要账号，不上传任何数据，不采集使用信息。

## 功能

### 快速链接网格

| 能力 | 说明 |
| --- | --- |
| 网格 | 列 1~16、行 1~6 可调，默认 6 列 × 4 行（每页 24 个），格子为正方形 |
| 排布 | 每格独立槽位；拖动重排是**交换**语义（两个格子互换，其余不动） |
| 操作 | 左键访问、右键新增/编辑、`1`~`9` 直达前九项 |
| 翻页 | 滚轮、横向拖动、页码按钮三种方式 |
| 拖动 | 长按 0.4 秒进入拖动，方块跟随指针，松手落到最近的格子 |
| 名称 | 可设短名称与完整名称；悬浮显示完整名称、网址与快捷键 |
| 图标 | 自动读取站点 favicon，也可本地上传自定义图标 |

### 组件插件（15 个）

时钟（数字 / 模拟 / 多时区）、问候语、搜索框、待办、笔记、天气、GitHub 贡献图、
NBA 比分、文学钟、留言板、笑话、工时统计、IP 信息、自定义 CSS、自定义 JS。
每个组件都能单独摆放、缩放、隐藏。

全新安装的默认布局自上而下为：**时钟 → 问候语 → 搜索框 → 快速链接**，搜索默认 Bing。

### 代理访问

- 可预置多个**代理节点**，每个链接单独选择用哪个节点，也可填自定义地址
- 支持 `http` / `socks5` / `socks4`
- 走浏览器级 **PAC 按域名路由**，不是全局代理
- 无规则时**不接管网络**；可另设「兜底代理」，留空则直连
- 节点不可达时可有兜底链路，不会把整台机器的网络拖死

> 浏览器只提供整个配置文件级别的代理 API，没有「单链接 / 单标签页」代理，
> 因此只能按域名路由——同一域名的所有访问共用一个节点。

### 书签备份

开启后，快捷链接会镜像到书签栏的 **「标签页备份书签，请勿删除」** 文件夹：

- 只镜像名称与网址，不含其他内容
- 删除链接不会立刻删书签，需手动点「同步」确认
- 只删除自己创建的书签，不碰你原有的任何书签
- 链接身份绑定内部 id，改网址、改名称都不会重复建书签

### 标签分享（可选）

把链接发布给指定的其他人，对方确认指纹后一键添加：

- **无需账号**：双方各自生成一对 P-256 密钥，服务端只存公钥
- 私钥不出浏览器，设置导出文件里也不含私钥
- 发布时选择接收者；对方核对指纹一致后才添加
- 更新后对方需手动刷新，不会自动推送
- 需要一个中转服务（扩展本身不建服务器）；局域网临时用可 `npm run share-server`，
  长期或公网使用见下方[「可选：中转服务部署」](#可选中转服务部署)

### 外观与数据

- 背景：Bing 每日壁纸、随机动图、纯色、渐变、自定义上传
- 配置存 `chrome.storage.sync`，跨设备跟随浏览器账号；超出单条上限会自动分片
- 自定义图标存 IndexedDB，不占同步配额（代价：不跨设备同步）
- 整套设置可导入 / 导出；侧边栏「持久化配置」可另存 / 恢复本机快照
- 设置侧边栏底部有离线教程页，涵盖链接、代理、分享、书签与备份

## 安装

需要 Node.js 18+。

```bash
npm install
npm run build:chromium        # 产物在 dist/chromium/
```

打开 Edge / Chrome 的扩展页 → 开启「开发人员模式」→「加载已解压的扩展程序」→
选择 `dist/chromium/` 目录。

> 浏览器**不能**把 zip 或 crx 直接拖进来安装，zip 只用于备份或分发。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存配置 |
| `favicon` | 读取站点图标 |
| `bookmarks` | 备份快捷链接到书签文件夹（可关闭） |
| `proxy` | 按链接配置代理（安装时会提示「更改代理设置」） |
| `<all_urls>`（可选） | 仅在你主动开启「读取站点标题」时申请，可随时撤回 |

**数据流向**：配置与链接都在本机，跟随浏览器账号同步，不向任何服务器上报。
唯一的网络请求是组件自身需要的公开接口（壁纸、天气、比分等）与你自建的中转服务。

## 项目结构

| 路径 | 说明 |
| --- | --- |
| `src/` | 扩展源码：组件插件在 `src/plugins/`，数据中间层在 `src/db/` 与 `src/lib/` |
| `target/` | 各平台 HTML / manifest 模板、图标、离线教程页，构建时自动复制 |
| `server/link-share-server.js` | 零依赖的标签分享中转服务（`npm run share-server`），自用可选 |
| `keys/chromium-pub.b64` | 固定扩展 ID 用的公钥（私钥不入库） |
| `scripts/` | 构建辅助脚本（扩展 ID 注入、文案提取） |

## 设计取舍

- **扩展 ID 固定**：用 `manifest.key` 固定，换目录或重装都不会变成新扩展，数据不丢
- **同步超限自动分片**：`storage.sync` 单项 8KB，超限会整批写入失败，已做分片规避
- **拖动落位不靠命中测试**：直接按格子编号取最近中心，避免弹层 / 跨页时命中错误
- **默认值只影响新装**：改默认布局不会覆盖已有用户的配置，需要时用一次性迁移
- **组件不各存副本**：状态统一从中间层读，避免多实例不同步

## 可选：中转服务部署

标签分享需要一个中转服务（扩展本身不建服务器）。**不需要分享功能就跳过本节**，
其它功能不受影响。

镜像已发布在 Docker Hub：`lindagao/huayuzhu-relay-node:1.0.2`
（<https://hub.docker.com/r/lindagao/huayuzhu-relay-node>）

### 部署前准备

| 需要 | 说明 |
| --- | --- |
| 一台能跑 Docker 的 Linux | 云主机 / 内网服务器 / NAS 均可；1Panel、宝塔等面板可直接导入 compose |
| 一个强随机令牌 | 登录管理界面用，也是分享签名的校验依据（`openssl rand -hex 24` 可生成） |
| 一个可用端口 | 默认 `8787`，需放行；公网建议前面挂 Nginx 终止 TLS |
| 一个持久化目录 | 挂到容器 `/app/data`；分享、密钥、日志、设置都在里面，备份就是打包它 |

### 启动

```bash
docker run -d --name huayuzhu-relay-node --restart unless-stopped \
  -p 8787:8787 -v "$(pwd)/data:/app/data" \
  -e RELAY_ADMIN_TOKEN='换成你的强随机令牌' \
  lindagao/huayuzhu-relay-node:1.0.2
```

用 compose：

```yaml
services:
  relay-node:
    image: lindagao/huayuzhu-relay-node:1.0.2
    container_name: huayuzhu-relay-node
    restart: unless-stopped
    ports: ["8787:8787"]
    environment:
      RELAY_ADMIN_TOKEN: "换成你的强随机令牌"
    volumes:
      - ./data:/app/data
```

```bash
mkdir -p ./data && docker compose up -d
```

管理界面 `http://<服务器IP>:8787/admin`（令牌登录）。把 `http://<服务器IP>:8787/`
填进扩展「标签分享」的服务地址；同一个地址也可作为「代理节点」。

### 面板里能改什么

| 配置 | 位置 | 说明 |
| --- | --- | --- |
| 代理访问是否需令牌 | 设置 | 浏览器 PAC 无法携带认证头，扩展直连时应关闭 |
| 是否允许访问私网 | 设置 | 只做外网中转建议关闭，防止被当作内网探测跳板 |
| 日志保留条数 | 设置 | 100 ~ 100000，超出丢弃最旧记录 |
| 管理令牌 | 设置 | 修改后立即生效，并持久化到 `data/settings.json` |
| 端口 / 反向代理子路径 | 只读展示 | 属启动参数，只能在启动容器时用环境变量设置 |

面板还能看概览、按类别/级别筛选日志、撤销任意分享。**密钥由扩展端生成**
（私钥始终不出浏览器），服务端只存公钥与指纹，面板可对每个已注册身份改名 /
禁用 / 删除，删除会连带撤销它发布的分享。

> 内网无外网时也可用离线包部署（作者自用，不随仓库分发）；镜像为 `linux/amd64`，
> ARM 机器需自行构建。签名协议、端口复用等实现约定见 [`MANUAL.md`](MANUAL.md)。
